# 拾遗潮 · Tide of Lost Things

> 「夏天结束之前，把丢失的话，一句一句捡回来。」

一款以「AI 娘」七位女主角为核心的**原创恋爱催泪视觉小说（Galgame）**。
近未来海滨城市「临汐市」，七位以人类少女形态生活了十二年的 AI 将在 8 月 31 日被法律强制下线；头戴牛皮纸袋的转学生「拾一」为寻找三年前被删除的儿时伴侣机「小舟」没说完的那句话而来——传说夏天最大的潮水之夜，海会把丢失的东西还回来，人称**拾遗潮**。

## 运行方式

```bash
cd galgame
python3 -m http.server 8765
# 浏览器打开 http://localhost:8765
```

（任何静态服务器均可，无需构建；纯 HTML/CSS/JS。）

## 内容规模

- **共通线**（序章 / 第一章 纸袋转学生 / 第二章 方舟与倒计时 / 第三章 夏至祭）+ **7 条个人线** + **真结局线「潮汐」**
- 9 条剧本共 **2600+ 条演出指令、1400+ 句台词、73 个选项节点**
- 每条个人线 **11 幕以上场景互动**，包含学校 / 咖啡馆 / 商业街 / 蛋糕店 / 游乐场（摩天轮）/ 海边 / 民宿合宿 / 夏祭等全部必含场所
- **23 个结局**：每线 奇迹 END / 余温 END / 潮落 END（刀）三档 + 真结局线 双结局
- **18 个 CG / 过场动画**（OP 开场动画 + 每线 3 个专属 CG + 共通花火 CG 等），全部 Canvas 程序化实时绘制
- **30+ 手绘矢量动态场景**（雨中车站、鲸落咖啡馆、星空天台、夏祭灯笼街、极夜雪原、拾遗潮夜海……），全部带动画
- **15 首程序化 BGM**（Web Audio 实时作曲：日常曲 / 各角色主题曲 / 倒计时 / 花火 / 刀曲 / 真结局曲）+ 20 种音效 + 角色语音音钉 + 环境音（雨/海浪/风/咖啡馆）

## 独创系统

| 系统 | 说明 |
|---|---|
| **沉默选项** | 关键抉择固定出现第三个「……（沉默）」，有时反而是最优解 |
| **回声选择** | 界面会回显你当初的选择，世界记得你说过的话 |
| **摘袋窗口** | 名场面出现「摘下纸袋」特殊按钮——时机对了是剧情炸弹，错过则走向不同分支 |
| **潮位好感** | 好感以角色主题色的「潮光涟漪」反馈，不显示数值 |
| **手机聊天 UI** | MiniMax 线内置聊天界面互动 |
| **真结局线** | 通关任意 3 条个人线后，标题画面解锁「◆ 潮汐」——七帆同渡之夜 |

## 系统功能

打字机文本 / 自动播放 / 快进 / 回看历史 / 6 存档位 + 自动存档 / 快速存读档 / 文字速度与音量设置 / CG 鉴赏室 / 结局图鉴 / 章节日期与下线倒计时 HUD / 存档即点即续。

## 工程结构

```
galgame/
  index.html            入口
  css/style.css         全部样式
  assets/sprites/       8 张透明立绘（由三视图自动抠图）
  js/data/characters.js 角色表
  js/engine/            引擎：core(主循环/指令执行) dialogue sprites bgkit+bgscenes(动态背景)
                        particles(粒子) audio(BGM作曲/音效) cg(CG动画+OP) save ui
  js/script/            剧本：common + 7 条个人线 + route_true
  tools/                立绘抠图脚本（Python，含 scipy 连通域去底）
  design/story_bible.md 故事圣经（世界观/结构/结局表）
```

## 制作说明

- 立绘来自用户提供的角色三视图设定图，经脚本自动切分、泛洪+连通域去背景生成透明 PNG。
- 全部背景、CG、音乐、音效均为代码实时生成，无外部素材版权问题。
- 台词与演出为原创剧本。
